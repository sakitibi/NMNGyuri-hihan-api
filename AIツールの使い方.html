AIツールの使い方

  1. まずpython 3.14をインストールします
  2. 次にユーザーディレクトリに新しいディレクトリを作成して
  3. cd 新しいディレクトリのパス を実行する
  4. 次に python3 -m venv venv を実行する
  5. source venv/bin/activate を実行してvenvを有効化する
  6. 次にここに移動します
  7. CodeメニューからDownload ZIP をクリックします
  8. 次にzipファイルを解凍してNMNGyuri-hihan-api-mainっていうディレクトリが出て来たら
  9. その中のbackendディレクトリ以外を全て削除します
  10. 次にbackendディレクトリの中身をgit clone を実行したディレクトリに移動する
  11. 次に rm -fr ./NMNGyuri-hihan-api-main する
  12. 次にpip install opencv-python numpy PIL easyocr する
  13. 最後にpython3 main.py したら起動成功!

2回目以降は

  1. cd 新しいディレクトリのパス を実行する
  2. source venv/bin/activate
  3. python3 main.py

だけでOK!
